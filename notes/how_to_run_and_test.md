# アプリの動かし方とテストの基本ガイド

Webアプリ開発では、「コードを書く」→「動かして確認する」→「修正する」というサイクルを何度も繰り返します。
このサイクルを回すための基本的な手順を解説します。

## 1. アプリを起動する (ローカル開発サーバー)

開発中は、自分のパソコンの中だけで動く「専用のWebサーバー」を立ち上げます。これを作るのに `Next.js` (このアプリのフレームワーク) が役立ちます。

### 手順

1. **ターミナルを開く**:
   VS Codeの下にあるパネル（ターミナル）を使います。

2. **ディレクトリを確認する**:
   コマンドを打つ場所が正しいか確認します。
   ```bash
   pwd
   ```
   出力の最後が `vizchess` になっていればOKです。

3. **起動コマンドを実行する**:
   以下のコマンドを入力して `Enter` を押します。
   ```bash
   npm run dev
   ```
   - **解説**: `npm` (Node Package Manager) に、「`dev` (開発モード)」というスクリプトを実行して！と命令しています。

4. **準備完了を待つ**:
   しばらくすると、以下のようなメッセージが表示されます。
   ```
   Ready in 1234ms
   - Local: http://localhost:3000
   ```
   これで、あなたのパソコンの `3000番ポート` という場所でアプリが動き始めました。

5. **ブラウザでアクセスする**:
   Webブラウザ (Chrome, Edge, Safariなど) を開き、アドレスバーに以下を入力して移動します。
   - URL: `http://localhost:3000`

   これで、あなたが作ったチェスアプリが表示されるはずです！🎉

### サーバーを止めるとき
ターミナルで `Ctrl + C` を押すと、サーバーを停止できます。

## 2. 動作確認（テスト）のやり方

アプリが表示されたら、開発者がやるべき「セルフチェック」のポイントがあります。
プログラミングの世界では、大きく分けて**2種類のテスト**を行います。

### A. 正常系テスト (Happy Path)
「普通に使ったときに、正しく動くか？」を確認します。

- **チェックリスト**:
  - [ ] ページがエラーなく表示されるか？
  - [ ] 白の駒をドラッグして、正しい場所に置けるか？
  - [ ] 黒の駒も同様に動かせるか？（このアプリは交互に操作します）
  - [ ] 「Show Scope」ボタンを押すと、盤面に色がつくか？
  - [ ] 駒を動かした後、手番表示 (White's Turn / Black's Turn) が切り替わるか？
  - [ ] 「Reset」ボタンで初期状態に戻るか？

### B. 異常系テスト (Edge Cases)
「変な操作をしたときに、壊れないか？」を確認します。バグはここで見つかることが多いです。

- **チェックリスト**:
  - [ ] **反則な動き**: ルール上動かせない場所に駒を置こうとしたらどうなる？（元の位置に戻るのが正解）
  - [ ] **自分を取る**: 自分の駒の上に自分の駒を置こうとしたら？
  - [ ] **画面サイズ変更**: ブラウザの幅をスマホくらい狭くしても、デザインが崩れて操作不能にならないか？
  - [ ] **連打**: ボタンを連打してもおかしくならないか？

## 3. エンジニアの必須道具「検証ツール (Developer Tools)」

ブラウザで動かしているときに「あれ、動かない？」と思ったら、ブラウザの裏側を見てみましょう。

1. ブラウザ画面上のどこかで **右クリック** → **「検証」** (Inspect) を選択。
2. 出てきたパネルの **「Console」** (コンソール) タブをクリック。

ここには、アプリからのメッセージやエラーが表示されます。
- **赤い文字**: エラー (Error)。プログラムが止まる原因です。
- **黄色い文字**: 警告 (Warning)。動くけど直したほうがいい箇所です。

開発中は、この「コンソール」を開きっぱなしにしておくのがお勧めです。

---

## 4. コードを書き換えてみよう

サーバー (`npm run dev`) を動かしたまま、VS Codeでファイルを編集して保存 (`Ctrl + S` / `Cmd + S`) してみてください。
例えば、`src/app/page.tsx` のタイトル文字 `VizChess` を `My Chess App` に変えて保存すると…？

**ブラウザを更新しなくても、自動で画面が変わります！**
これを「ホットリロード (Hot Reload)」と言い、現代のWeb開発のとても便利な機能です。

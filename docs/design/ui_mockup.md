# UI モックアップ & レイアウト

## 1. 画面構成 (Wireframe)
いずれの画面構成においても、画面内に盤面が全て収まるように最低限サイズを調整する。

### メイン画面 (デスクトップ)
左右 2カラム構成を基本とする。

```
+---------------------------------------------------------------+
|  [Header] Logo: Chess Viz     [About] [Github] [Settings]     |
+---------------------------------------------------------------+
|                                                               |
|   +-----------------------+   +---------------------------+   |
|   |                       |   |      [Game Info]          |   |
|   |                       |   |  Black: CPU (Level 1)     |   |
|   |                       |   |                           |   |
|   |      Chess Board      |   |  [Move History List]      |   |
|   |      (600px x 600px)  |   |  1. e4 e5                 |   |
|   |                       |   |  2. Nf3 ...               |   |
|   |                       |   |                           |   |
|   |                       |   |  -----------------------  |   |
|   |                       |   |      [Control Panel]      |   |
|   +-----------------------+   |                           |   |
|                               |  [Board Scope]            |   |
|                               |  ( ) On  (•) Off          |   |
|                               |                           |   |
|                               |  [Action Buttons]         |   |
|                               |  [Undo] [Reset] [Flip]    |   |
|                               +---------------------------+   |
|                                                               |
+---------------------------------------------------------------+
```

### レスポンシブ (モバイル)
縦 1カラム構成に変更。盤面を最優先し、コントロールパネルは下部に配置。

```
+---------------------------+
| [Header] Chess Viz [Menu] |
+---------------------------+
| [Opponent Info]           |
+---------------------------+
|                           |
|       Chess Board         |
|       (Width: 100%)       |
|                           |
+---------------------------+
| [Your Info]               |
+---------------------------+
| [Board Scope: On / Off]   |
| [Action Buttons]          |
+---------------------------+
| [History (Collapse)]      |
+---------------------------+
```

## 2. コンポーネント構成案
- `StatsPanel`: プレイヤー名、捕獲した駒、評価値（将来用）を表示
- `ChessBoardWrapper`: `react-chessboard` をラップし、カスタムレイヤー（可視化用）を重ねるコンテナ
- `ControlPanel`: ゲーム操作（待った、リセット）とガイド設定（モード切替）を集約
- `HistoryView`: 棋譜リスト。クリックで過去の局面に戻れる機能を持たせる

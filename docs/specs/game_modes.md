# ゲームモード仕様 (Game Modes)

## 1. ガイド機能
本アプリのメイン機能。全ての対局において、可視化機能を利用しながら対局できる。
- **対象**: 初心者〜中級者
- **特徴**: リアルタイムで盤面状況が色分けされる。
- **設定オプション**:
  - `Board Scope`: 画面下部のボタンからオンオフの切り替えが可能
  - `Piece Scope`: マークしたい駒をタップすることでオンオフの切り替えが可能

## 2. 対戦形式

### Player vs Player (Local)
- 1つの画面で交互に操作するモード。
- 「盤面反転 (Flip Board)」ボタンで視点を切り替え可能にする。

### Player vs CPU (Local AI) - *Future*
- `stockfish.js` などを利用したブラウザ内AIとの対戦。
- 難易度調整機能 (Level 1~10)。

### Player vs Player (Online) - *Future*
- WebSocket等を利用したリアルタイム通信対戦。
- 待った機能はこのモードでは無効とする。
